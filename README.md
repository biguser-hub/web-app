# Онлайн-платформа управления проектами

Учебный проект для производственной практики.

В приложении будут регистрация и авторизация пользователей, проекты, задачи,
комментарии, уведомления, журнал событий, профиль пользователя и панель
администратора.

## Технологии

- Vue 3
- Vite
- Vue Router
- Supabase (PostgreSQL и авторизация)
- обычный CSS

## Возможности

- регистрация, вход и восстановление пароля;
- редактирование профиля;
- создание и поиск проектов;
- управление участниками;
- создание, редактирование и удаление задач;
- назначение исполнителей, статусы и приоритеты;
- комментарии, уведомления и журнал действий;
- административная панель;
- адаптивный интерфейс.

## Запуск

```bash
npm install
npm run dev
```

Перед запуском нужно выполнить файл `supabase/schema.sql` в SQL Editor проекта Supabase и создать `.env.local` по примеру `.env.example`.

Подробная инструкция и учебные материалы находятся в папке `docs`.
