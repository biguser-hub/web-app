# Онлайн-платформа управления проектами

Учебный проект для производственной практики.

В приложении будут регистрация и авторизация пользователей, проекты, задачи,
комментарии, уведомления, журнал событий, профиль пользователя и панель
администратора.

## Технологии

- Vue 3
- Vite
- Vue Router
- Supabase (PostgreSQL и авторизация)
- обычный CSS

Проект находится в разработке.
