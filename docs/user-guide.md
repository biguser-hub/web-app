# Руководство пользователя

## Регистрация и вход

На странице регистрации нужно заполнить имя, электронную почту и пароль. После регистрации пользователь переходит на страницу входа. Если пароль забыт, можно запросить ссылку для его изменения.

## Работа с проектами

В разделе «Проекты» отображается список доступных проектов. Их можно искать по названию и фильтровать по статусу. Кнопка «Новый проект» открывает форму создания.

Внутри проекта находятся доска задач и список участников. Владелец может добавить зарегистрированного пользователя в проект. После этого пользователь становится доступен в списке исполнителей.

## Работа с задачами

Задача содержит название, описание, статус, приоритет, исполнителя и срок. Её можно редактировать, перемещать между статусами и удалять. В карточке задачи пользователи оставляют комментарии.

## Уведомления и профиль

При назначении задачи исполнитель получает уведомление. На странице профиля можно изменить имя, телефон и информацию о себе.

## Администратор

Администратор просматривает общую статистику, меняет роли пользователей, блокирует аккаунты и удаляет проекты.
