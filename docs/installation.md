# Инструкция по установке

1. Установить Node.js версии 20 или новее.
2. Скачать репозиторий и выполнить `npm install`.
3. Создать проект Supabase.
4. Открыть SQL Editor и выполнить файл `supabase/schema.sql`.
5. Скопировать `.env.example` в `.env.local` и указать адрес проекта и publishable key.
6. Запустить приложение командой `npm run dev`.

Для назначения администратора сначала нужно зарегистрировать пользователя, затем выполнить последний SQL-запрос из файла схемы, заменив пример электронной почты на настоящую.

Для восстановления пароля в Supabase необходимо указать адрес опубликованного сайта в Authentication → URL Configuration. Для отправки писем на произвольные адреса подключается SMTP.

Сборка проверяется командой `npm run build`. GitHub Actions автоматически собирает сайт и публикует папку `dist` на GitHub Pages.
