# Отчёт по производственной практике

## Цель работы

Целью практики являлась разработка веб-приложения для управления проектами. В приложении требовалось реализовать пользователей, проекты, задачи, уведомления и административную панель.

## Анализ и проектирование

Для интерфейса выбран Vue 3. Он позволяет разделить приложение на страницы и компоненты. Для хранения информации выбрана база PostgreSQL в Supabase. Структура включает профили, проекты, участников, задачи, комментарии, уведомления и журнал событий.

## Выполненная работа

На первой неделе была подготовлена структура проекта, создана схема базы данных и реализованы регистрация, вход, профиль пользователя и список проектов. Добавлены маршруты страниц и подключение к базе.

На второй неделе разработаны создание и изменение задач, назначение исполнителя, статусы, удаление, комментарии и уведомления. Создана административная панель со статистикой и управлением пользователями. Интерфейс адаптирован для телефонов.

На третьей неделе были упрощены повторяющиеся части кода, добавлены индексы базы данных и правила доступа. Проведена проверка форм, маршрутов и сборки. Подготовлены руководство пользователя и инструкция по установке.

## Проверка проекта

Проверялись регистрация и вход, создание проектов, поиск, создание и редактирование задач, комментарии, уведомления, профиль и права администратора. Сборка приложения выполняется без ошибок.

## Итог

В результате создано работоспособное многостраничное по структуре веб-приложение. Оно размещается на GitHub Pages и использует облачную PostgreSQL-базу Supabase.
